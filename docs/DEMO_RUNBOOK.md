## คำถามกรรมการ (ตอบสั้น)
- **ต่างจากแอปบัญชีอย่างไร** → แอปบัญชีบันทึกอดีต เรา*ทำนายเป็นความน่าจะเป็น แตกกิ่ง "ถ้า..." และลงมือ (โทรตามเงิน) แล้วมีหลักฐานย้อนตรวจได้*
- **ข้อมูลไม่ครบแล้วแม่นแค่ไหน** → backtest บนจอ: ช่วง 80% ครอบคลุมจริง 75.7% เรารายงานตรงๆ ไม่ปัด และช่วงพยากรณ์รวมความไม่แน่นอนของพารามิเตอร์แล้ว ข้อมูลเดโมเป็นสังเคราะห์ ของจริงต้องรันกับประวัติลูกค้า
- **LLM เดาตัวเลขไหม** → ไม่ LLM แปลคำพูดเป็นพารามิเตอร์ (whitelist + ขอบเขตค่า) ตัวเลขมาจากโค้ด seed ซ้ำได้ มีเทสต์ 22 ข้อ
- **ใครรับผิดชอบถ้า AI โทรพลาด** → เปิดเผยว่าเป็น AI ทุกสาย เจ้าของอนุมัติสคริปต์ ห้ามข่มขู่ (พรอมต์ถูก lint) สายที่ปฏิเสธลดความน่าจะเป็น ไม่ตื๊อ
- **ทำไมผู้ให้สินเชื่อควรเชื่อ** → ledger เป็น commit ที่ผูก hash ของ input + เวอร์ชัน engine รันซ้ำได้ ใช้ FCF เปอร์เซ็นไทล์ 5% ไม่ใช่ค่าเฉลี่ย (ในเดโมวงเงินใหม่ = 0 เพราะธุรกิจตึง — ระบบไม่ใจดีเกินจริง)
- **ทำไมต้องเสียง** → การโทรตามเงินคือการลงมือจริงที่เปลี่ยนตัวเลขการเงิน และเจ้าของร้านใช้มือไม่ว่าง
- **ธุรกิจอยู่ตรงไหน** → SaaS รายเดือนจาก SME + ผู้ให้สินเชื่อซื้อข้อมูลที่ตรวจสอบได้ + ช่องทางผ่านผู้ทำบัญชี
- **คู่แข่ง** → มีเครื่องมือพยากรณ์เงินสดอยู่ จุดต่างคือ แตกกิ่ง + ลงมือ + หลักฐาน (ไม่ได้อ้างว่าไม่มีใครทำ)
- **กฎหมาย/PDPA** → เป็นเครื่องมือวางแผน ไม่ใช่คำแนะนำลงทุน ข้อมูลเดโมสังเคราะห์ ของจริงใช้รีโปส่วนตัว/เข้ารหัส; เพดานดอกเบี้ย 15%/36% เป็นค่าอ้างอิงที่ต้องตรวจกับผู้รู้

## อย่าพูด
- ห้ามอ้างความแม่นยำโลกจริง หรือตัวเลขตลาดโดยไม่มีแหล่งอ้างอิง
- ห้ามอ้างว่า "ไม่มีใครทำ" / "รับประกัน 95/100"
- อย่าเอาเพดาน 15% ไปตัดสินสินเชื่อธนาคาร (ใช้กับเจ้าหนี้นอกสถาบันการเงินเท่านั้น)
