# ส่งดีไซน์จาก Canva ให้ Claude ทำเป็นโค้ด
## เพื่อนต้องส่งอะไร (ครบ 5 อย่างจะเร็วที่สุด)
1. **ลิงก์ Canva ของแต่ละหน้า** (ตั้งแชร์เป็น "ทุกคนที่มีลิงก์ดูได้") ตั้งชื่อหน้าตามนี้: `landing`, `dashboard`, `branch-diff`, `call`, `debt`, `merge-ledger`, `mobile`
2. **ชุดสี** เป็น hex ครบ: พื้นหลัง, การ์ด, เส้นขอบ, ข้อความหลัก/รอง, สีเน้น, สีผิด/ลบ, สีเตือน, สีกิ่ง (branch)
3. **ฟอนต์**: ชื่อ 2 ตัว (หัวข้อ/เนื้อหา) ที่มีใน Google Fonts และรองรับไทย + ขนาดที่ใช้ (หัวข้อ/เนื้อหา/ตัวเลขใหญ่)
4. **ไฟล์ภาพ**: โลโก้และไอคอนเป็น **SVG** (ถ้าไม่ได้ PNG โปร่งใส 2×), ภาพประกอบ/พื้นหลัง PNG หรือ WebP
5. **หมายเหตุอนิเมชัน** 1–2 บรรทัดต่อจุด (เช่น "ตัวเลขนับขึ้นใน 0.8 วิ", "แบนด์กราฟค่อยๆ เปลี่ยนใน 0.6 วิ")

## กติกา
- ใช้ตัวเลขจริงจาก `docs/DEMO_RUNBOOK.md` (77% → 52% → 93%) ในแบบ ห้ามแต่งเลข
- ทุกหน้ามีป้าย "ข้อมูลตัวอย่างสังเคราะห์" และข้อความ "เป็นเครื่องมือวางแผน ไม่ใช่คำแนะนำลงทุน"; สายโทรต้องมีป้าย "AI"
- Contrast ข้อความอ่านง่ายบนโปรเจกเตอร์ (ตัวหนังสือหลักไม่เล็กกว่า 16px บนจอเว็บ)

## ผมทำอะไรต่อให้ได้
ส่งลิงก์ Canva + ข้อ 2–5 มาในแชทนี้ ผมอ่านดีไซน์ (ผ่านตัวเชื่อม Canva) แล้วแก้ `web/src/styles.css`, `App.jsx`, `FanChart.jsx` ให้ตรง build ใหม่ และส่งกลับโฟลเดอร์ จากนั้นคุณ `git push` → Render deploy เอง
- ส่งทีละหน้าได้ ผมทำทีละหน้า (แนะนำเริ่ม `dashboard` เพราะเป็นหน้าที่กรรมการเห็นนานสุด)
- ถ้าดีไซน์ต้องการหน้าใหม่ (เช่น landing) ผมเพิ่ม route ให้

## วิธีกันงานชนกัน (ถ้าเพื่อนแก้โค้ดเองด้วย)
เพื่อนแตก branch ของตัวเอง แก้เฉพาะ `web/` แล้วเปิด PR ห้ามแตะ `engine/` และ `data/seed.json` (เทสต์ผูกกับตัวเลขเดโม) หลังแก้ต้อง `cd web && npm run build` แล้ว commit `web/dist` ด้วย เพราะ Render เสิร์ฟจาก dist ที่ commit ไว้

## ข้อมูลใหม่ที่หน้าเว็บดึงได้ (ให้เพื่อนออกแบบช่องไว้)
| ส่วน | endpoint | สิ่งที่แสดง |
|---|---|---|
| แผง "ขอบเขตความปลอดภัย" | `GET /api/guardrails` | `rules_th` (กฎเป็นข้อๆ), `status[]` (ลูกหนี้แต่ละรายโทรได้ไหมตอนนี้ + `reason_th`), `stopped`, `log[]`, `legal_note_th` |
| ปุ่มโทร | `POST /api/guard/start_call` | `allowed`, `code`, `reason_th`, `demo_override` ถ้าไม่ผ่านต้องปิดปุ่มและโชว์เหตุผล |
| ตัวอย่างแชต LINE | `GET /api/line/preview` | `text` ข้อความสรุปรายสัปดาห์ (ออกแบบเป็นบับเบิลแชต) |
| ปุ่มส่ง LINE | `POST /api/line/weekly` | `sent`, `reason_th` |

รหัสเหตุผล (`code`): `ok`, `outside_hours`, `daily_limit`, `weekly_limit`, `stopped`, `unknown_debtor`, `third_party`
